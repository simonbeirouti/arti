# Shared suggestions and publication

The model generates text for public coordination. It does not choose a repository, deployment, actor, reply target or privileged command. Shared code changes still require an approved public task scope with `projectId`; execution resolves the canonical collective repository and its task fork.

Use the focused tests for privacy projection, no simulation-source reuse, argument validation, authority changes and original-key replay. Deterministic tests establish these boundaries only. They do not establish a live model response or publication.

For a cloud verification, first pass the release-pinned real model evaluation and explicitly enable live mode with configured caps. Observe a real public discussion receipt, its `agent` origin and the linked reply. Record reported model usage separately from unknown reservations. Do not claim a suggestion is a tested change or deployed result.
