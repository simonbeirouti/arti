# Publication operations

Inspect immutable commit and bundle hash for every release. Simulation receipts identify simulation explicitly. Failed or stale goal work must not promote. Recover by retrying a task from current canonical HEAD; never force a stale promotion. Roll back to a previous retained bundle if publication is unhealthy. Repository history remains available to explain the change.

Live activation is a separate operator configuration, requiring budget, provider resources, credentials, protected operator identity, and isolated entity domains. No credentials belong in entity repositories or generated bundles.
